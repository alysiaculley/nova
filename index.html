🐙 Professional Git & GitHub Command Guide

Your cheat-sheet for mastering version control in AntiGravity IDE

1. Initialize Local Project

git init
git branch -M main

Transforms your folder into a Git repository and sets `main` as the default branch.

2. Track & Commit Changes

git status
git add .
git commit -m "feat: add interactive focus timer"

Stages changed files and saves an atomic snapshot with a clear description.

3. Connect to GitHub

git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main

Links your computer to your online GitHub repository and uploads your commits.

4. Feature Branch Workflow

git checkout -b feature/new-widget
# ... make changes ...
git commit -m "feat: add weather widget"
git push -u origin feature/new-widget

How professional teams build features without risking the main production code!
